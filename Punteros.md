# *- Creación*
Cuando se crea un puntero por primera vez antes de crear el *NEW*, el puntero tendrá valor *NULL*, pero ocupará el espacio de memória que usará.

# *- Inserción*
Cuando se copia en el *NEW* por primera vez se crea a parte de la variable el puntero en memoria que apuntará a la variable **VIDA**

# *- Modificación*
Usaremos el caracter * antes de usar la modificación de valor para no modificar el puntero, sinó utilizarlo para modificar la variable original.
